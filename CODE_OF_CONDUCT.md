# Código de conducta

Kafka es un espacio para gente que cuida la lectura y a quienes leen. Esperamos que todas las personas que participen, en *issues*, *pull requests* o cualquier otro canal, actúen así:

- **Respeta.** Critica el trabajo, no a la persona. Asume buena fe.
- **Sé claro y amable.** Explica el porqué de una crítica y propón una salida.
- **Incluye.** Cada persona llega con un contexto distinto (idioma, experiencia, ayudas técnicas). Pregunta antes de suponer.
- **Cuida lo ajeno.** No publiques datos personales de nadie sin permiso.

No se tolera el acoso, el lenguaje discriminatorio, las amenazas ni la publicidad no solicitada.

## Aplicación

El mantenedor puede editar o eliminar comentarios, cerrar *issues* y bloquear a quien incumpla esto. Para reportar un problema escribe en privado a través de [GitHub](https://github.com/lermajonathan); se tratará con discreción.

Este código se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
